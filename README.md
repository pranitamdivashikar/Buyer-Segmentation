# Machine Learning Based Buyer Segmentation & Investment Profiling

## Project Overview
This project applies unsupervised machine learning algorithms (K-Means and Hierarchical Clustering) to discover buyer segmentation profiles and investment patterns for Parcl Co. Limited, in collaboration with Unified Mentor.

## Key Deliverables
- **Real_Estate_Buyer_Segmentation.ipynb**: Complete end-to-end data processing, feature scaling, clustering evaluation, and profiling.
- **app.py**: Interactive multi-tab Streamlit dashboard providing executive analytics and customer controls.
- **segmented_real_estate_clients.csv**: Clustered dataset containing persona mappings and 2D PCA coordinates.

## Discovered Buyer Personas
- **C1: Global Investors**: High-capital investors purchasing multiple properties with cross-border interests.
- **C2: First-Time Buyers**: Younger demographic, primary residential focus with 100% loan dependency.
- **C3: Corporate Buyers**: Institutional/company accounts purchasing residential portfolios without financing.
- **C4: Luxury Investors**: High satisfaction scores and premium property allocations.

## Tech Stack
- Python, Pandas, Scikit-Learn, Plotly, Streamlit
